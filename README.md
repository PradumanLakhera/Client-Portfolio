# Client Portfolio Website

A premium, responsive portfolio website designed and developed for a client.

# Overview

A minimal, editorial-style portfolio focused on presenting the client's:

- Professional experience
- Education
- Projects
- International experience
- Awards and recognition
- Certificates and supporting documents
- Contact information

# Tech Stack

- React
- JavaScript
- Vite
- HTML
- CSS

# Features

- Full-screen vertical navigation
- Responsive design
- Interactive experience sections
- Project showcase
- Education timeline
- Certificate portal
- Certificate document viewer
- Keyboard and navigation controls
- Mobile-friendly layout
